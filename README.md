# 🎮 Dota 2 Loadout Generator

Автоматизированный сбор данных о героях с dota2protracker.com и создание конфигураций для Dota 2

## 🚀 Быстрый запуск в один клик

1. **Скачайте проект** и распакуйте в любую папку
2. **Двойной клик** по файлу `run_d2loadout.bat` (или запустите через cmd)
3. **Дождитесь завершения** - программа автоматически все сделает

> ⚠️ **Важно**: Если используете PowerShell, запускайте как `cmd /c run_d2loadout.bat`

## 📋 Что нужно установить

- **Python 3.8+** с [официального сайта](https://www.python.org/downloads/)
    - ⚠️ При установке обязательно отметьте "Add Python to PATH"
- **Google Chrome** с [официального сайта](https://www.google.com/chrome/)

## ✨ Возможности

- **🚀 Оптимизированный скрапинг** - сбор данных за один проход браузера
- **📊 Актуальная статистика** - данные за последние 8 дней
- **⚙️ Автоматические конфигурации** - создание и копирование в Steam
- **🔄 Резервное копирование** - сохранение старых конфигураций
- **🤖 Полная автоматизация** - от установки до готовых конфигураций
- **📍 Отображение прогресса** - видно какая позиция парсится

## 🎯 Результат

После завершения:

- Откройте Dota 2
- Зайдите в режим выбора героев
- Увидите новые конфигурации с мета-статистикой

## 🛠️ Ручное использование

```bash
# Тихий режим (рекомендуется)
python dota2_data_scraper/main.py --quiet

# Полные логи для диагностики
python dota2_data_scraper/main.py

# Параметры D2PT фильтров
# period=auto — выбирается по дате последнего Dota патча:
# - если патчу < 8 дней -> period=patch
# - иначе -> period=8 (8 days)
python dota2_data_scraper/main.py --period auto --min-matches 20 --mmr 7000

# Можно задать period вручную
python dota2_data_scraper/main.py --period 8 --min-matches 20 --mmr 7000

# Только скрапинг данных
python dota2_data_scraper/main.py --scrape-all

# Только создание конфигураций
python dota2_data_scraper/main.py --config

# Видимый браузер для отладки
python dota2_data_scraper/main.py --no-headless
```

## 📁 Структура проекта

```
d2loadout/
├── run_d2loadout.bat           # 🚀 Запуск в один клик
├── requirements.txt            # Зависимости Python
├── venv/                       # Виртуальное окружение
└── dota2_data_scraper/         # Основной код
    ├── main.py                 # Точка входа
    ├── modules/                # Модули программы
    │   ├── core/              # Основная логика
    │   ├── scrapers/          # Скраперы данных
    │   ├── utils/             # Утилиты
    │   └── config/            # Конфигурации
    ├── configs/               # Выходные файлы
    └── requirements.txt       # Зависимости (дубликат)
```

## 📊 Выходные файлы

- `configs/heroes_data.csv` - данные героев с фасетами
- `configs/heroes_no_facets.csv` - данные героев без фасетов
- `configs/hero_configs.json` - конфигурации для Dota 2
- Автоматическое копирование в Steam директории

## 🔧 Если что-то пошло не так

1. **Проблемы с Python**: Убедитесь что Python установлен и добавлен в PATH
2. **Проблемы с Chrome**: Установите Google Chrome или запустите с `--no-headless`
3. **Ошибки скрапинга**: Проверьте интернет-соединение
4. **Диагностика**: Запустите `python dota2_data_scraper/main.py --no-headless`
5. **PowerShell**: Используйте `cmd /c run_d2loadout.bat` или двойной клик
