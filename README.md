# Dota 2 Loadout Generator (lite)

Сбор статистики героев через D2PT API и создание конфигураций для Dota 2. Без Selenium и браузера.

## Быстрый запуск в один клик

1. **Скачайте проект** и распакуйте в любую папку
2. **Двойной клик** по файлу `run_d2loadout.bat` (или запустите через cmd)
3. **Дождитесь завершения** - программа автоматически все сделает

> **Важно**: Если используете PowerShell, запускайте как `cmd /c run_d2loadout.bat`

## Что нужно установить

- **Python 3.8+** с [официального сайта](https://www.python.org/downloads/)
    - При установке обязательно отметьте "Add Python to PATH"

Зависимости (pandas, numpy, requests) ставятся из `requirements.txt` автоматически.

## Возможности

- **D2PT API** - статистика героев без браузера
- **Актуальная статистика** - period=auto (патч или последние 8 дней)
- **Автоматические конфигурации** - создание и копирование в Steam
- **Резервное копирование** - сохранение старых конфигураций
- **Полная автоматизация** - от установки до готовых конфигураций

## Результат

После завершения:

- Откройте Dota 2
- Зайдите в режим выбора героев
- Увидите новые конфигурации с мета-статистикой

## Ручное использование

```bash
# Тихий режим (рекомендуется)
python main.py --quiet

# Полные логи для диагностики
python main.py

# Параметры D2PT фильтров
# period=auto — выбирается по дате последнего Dota патча:
# - если патчу < 8 дней -> period=patch
# - иначе -> period=8 (8 days)
python main.py --period auto --min-matches 20 --mmr 7000

# Можно задать period вручную
python main.py --period 8 --min-matches 20 --mmr 7000

# Только создание конфигураций из уже скачанного CSV
python main.py --config
```

## Структура проекта

```
d2loadout/
├── run_d2loadout.bat           # Запуск в один клик
├── main.py                     # Точка входа
├── requirements.txt            # Зависимости Python
├── configs/                    # Выходные файлы
└── dota2_data_scraper/         # Основной код
    ├── main.py
    ├── modules/
    │   ├── core/              # DataManager, ConfigProcessor
    │   ├── scrapers/          # D2PT API client
    │   ├── utils/             # Steam, patch period
    │   └── config/            # Layout optimizer
    └── requirements.txt
```

## Выходные файлы

- `configs/heroes_data.csv` - данные героев из API
- `configs/processed_heroes.csv` - обработанные данные
- `configs/hero_configs.json` - конфигурации для Dota 2
- Автоматическое копирование в Steam директории

## Если что-то пошло не так

1. **Проблемы с Python**: Убедитесь что Python установлен и добавлен в PATH
2. **Ошибки API**: Проверьте интернет-соединение
3. **Диагностика**: Запустите `python main.py --debug`
4. **PowerShell**: Используйте `cmd /c run_d2loadout.bat` или двойной клик
